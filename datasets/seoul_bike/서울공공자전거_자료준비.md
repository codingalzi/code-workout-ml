# **1. 폴더 구성**

먼저 다음과 같이 파일을 배치한다.

```
P5/
├─ p5_prepare_seoul_bike(1).py
├─ raw_2025/
│  ├─ (2025년 대여이력 CSV 파일들)
│  └─ ...
└─ raw_2024/
   ├─ (2024년 대여이력 CSV 파일들)
   └─ ...
```

ZIP 파일은 압축을 해제해야 한다. 현재 코드는 폴더 안의 `.csv` 파일을 모두 찾아 처리한다.

# **2. 2025년 자료 실행**

코드 앞부분은 그대로 두면 된다.

```
YEAR = 2025ENCODING = "cp949"RAW = Path("raw_2025")MIN_RENTALS = 1000
```

VS Code에서 P5 폴더를 열고 터미널에서 실행한다.

```
python "p5_prepare_seoul_bike(1).py"
```

성공하면 다음 파일이 생성된다.

`p5_station_profiles_2025.csv`

이 파일을 P5 v9 노트북에서 사용하려면 데이터 불러오기 부분을 다음처럼 바꾼다.

```
DATA_FILE = "p5_station_profiles_2025.csv"
```

# **3. 2024년 자료 실행**

코드에서 두 줄만 수정하고 다시 실행한다.

```
YEAR = 2024RAW = Path("raw_2024")
```

이번에는 \*\*`p5_station_profiles_2024.csv`\*\*가 생성된다.

# **실행 전에 확인할 중요한 사항**

현재 코드는 다음 열이 원자료에 있다고 가정한다.

`대여일시`, `대여 대여소번호`, `대여 대여소명`, `반납일시`, `반납 대여소번호`, `반납 대여소명`

실제 파일에서 열 이름이 다르면 `KeyError`가 발생할 수 있다. 또한 파일 인코딩이 `cp949`가 아니면 읽기 오류가 생길 수 있다.

원자료의 열 이름은 다음의 간단한 코드로 확인할 수 있다.

```
from pathlib import Pathimport pandas as pdfile = next(Path("raw_2025").rglob("*.csv"))print(pd.read_csv(file, encoding="cp949", nrows=0).columns.tolist())
```

현재 코드에는 **연간 대여·반납 모두 1,000건 이상이며, 12개월 모두 대여 기록이 있는 대여소만 포함**하는 조건도 있다. 따라서 신설 대여소나 이용량이 적은 대여소는 제외된다.

**추천하는 방법:** 우선 2025년 원자료를 압축 해제한 후, CSV 하나의 열 이름을 위 코드로 확인해 보자. 그 결과가 예상한 구조와 일치하면 전체 변환 코드를 실행하면 된다.
